『혼자 공부하는 파이썬』

윤인성 · 파이썬 · 프로그래밍 기초
🟢~🟡 기본~발전
왜 추천하는가

이미 파이썬으로 여러 프로젝트를 만들어 본 학생에게 다시 입문서를 추천하는 것은 조금 의외일 수 있습니다. 하지만 프로젝트형 책을 따라가다 보면 크롤링·GUI·이미지 처리·데이터 분석·AI 예제까지 빠르게 경험하는 대신, ‘코드를 보고 따라서 입력할 수 있다’와 ‘왜 이렇게 작성해야 하는지 이해한다’가 섞일 수 있습니다. 이 책의 역할은 처음부터 다시 시작하는 것이 아니라 1학기 실습에서 생긴 빈칸을 메우는 것입니다.

무엇을 배울 수 있는가

예를 들어 for문과 리스트를 이용해 조건에 맞는 데이터를 골라낸 코드를 따라 작성했다고 해 보겠습니다. 이제는 for문이 왜 필요한지, data가 어떤 자료형인지, append()가 무엇을 변화시키는지, 같은 기능을 함수로 만들면 어떤 장점이 있는지, 리스트와 딕셔너리를 언제 구분해 써야 하는지, 예외가 발생했을 때 프로그램이 멈추지 않게 하려면 어떻게 해야 하는지를 설명할 수 있어야 합니다. 이 질문에 답할 수 있을 때 ‘코드를 따라 쓰는 사람’에서 ‘코드를 이해하고 수정하는 사람’으로 넘어갑니다.

1학기 책과 어떻게 연결되는가

1학기 책이 ‘이런 프로그램도 만들 수 있구나!’라는 넓은 경험을 주었다면, 『혼자 공부하는 파이썬』은 ‘내가 사용했던 코드가 왜 이렇게 작동하는지 설명해 보자’로 이동하게 합니다. 프로젝트 경험 → 프로그래밍 기초의 체계화라는 연결입니다.

이런 학생에게 특히 추천

예제는 따라 만들었지만 이제는 코드를 보지 않고 스스로 바꾸어 보고 싶은 학생

생각해 볼 질문 — 예제 코드를 보지 않고도 문제를 작은 단계로 나누어 함수와 자료구조로 표현할 수 있을까?

『파이썬 알고리즘 인터뷰』

박상길 · 자료구조 · 알고리즘 · 컴퓨터과학
🟠 심화
왜 추천하는가

두 번째부터는 ‘프로그래밍’과 ‘컴퓨터과학’의 차이를 경험하게 합니다. 프로그램을 만드는 능력과 문제를 효율적으로 해결하는 능력은 완전히 같은 것이 아닙니다. 이 책은 배열·연결 리스트·스택·큐·해시·트리·그래프 같은 자료구조와 여러 알고리즘을 파이썬 코드 문제를 통해 다루기 때문에, 고1 완독용보다는 2학년부터 관심 영역을 골라 읽는 심화 독서로 적절합니다.

무엇을 배울 수 있는가

학생 10명의 이름 중 한 명을 찾는 것은 처음부터 순서대로 확인해도 됩니다. 하지만 데이터가 1억 명이라면 상황이 달라집니다. 데이터를 어떤 형태로 저장할지, 처음부터 모두 확인해야 하는지, 미리 정렬하면 더 빠르게 찾을 수 있는지, 메모리를 더 사용하면 시간을 줄일 수 있는지를 고민해야 합니다. 여기에서 컴퓨터과학은 ‘정답이 나오는가?’뿐 아니라 ‘얼마나 효율적으로 정답을 구하는가?’를 중요하게 본다는 사실을 알게 되고, 시간복잡도와 공간복잡도라는 개념으로 이어집니다.

1학기 책과 어떻게 연결되는가

1학기에는 40가지 서로 다른 프로그램을 만들었다면, 이제는 프로그램의 겉모습보다 내부로 들어갑니다. 데이터를 어떻게 저장할지, 문제를 어떤 단계로 나눌지, 어떤 알고리즘이 더 효율적인지를 고민하면서 ‘무엇을 만들까?’에서 ‘어떻게 더 잘 해결할까?’로 질문이 발전합니다.

이런 학생에게 특히 추천

프로그램을 만드는 것보다 문제를 더 빠르고 효율적으로 해결하는 방법을 찾는 것이 재미있는 학생

생각해 볼 질문 — 같은 정답을 구하는 두 알고리즘 가운데 어떤 것이 더 효율적인지 어떻게 비교할 수 있을까?

추천 판단: ★★★★★

『파이썬 라이브러리를 활용한 데이터 분석』

웨스 맥키니 · 데이터과학 · 파이썬 · pandas · NumPy
🟠 심화
왜 추천하는가

1학기 책에는 이미 데이터 분석·시각화 프로젝트가 들어 있습니다. 그렇다면 다음에는 ‘데이터 분석 프로그램 하나를 만들어 봤다’에서 ‘실제 데이터 분석은 어떤 과정을 거치는가?’로 올라가야 합니다. 이 책은 NumPy·pandas·Jupyter 등을 이용한 데이터 분석을 체계적으로 다루기 때문에, 파이썬을 현실의 데이터를 연구하는 도구로 확장하는 데 적합합니다.

무엇을 배울 수 있는가

실제 데이터는 교과서처럼 깔끔하지 않습니다. 예를 들어 설문 자료에 숫자와 문자열이 섞여 있고, 빈 값이 있으며, 범위를 벗어난 값이 있다면 그대로 평균을 내서는 안 됩니다. 데이터 분석에서는 수집 → 정리 → 결측치 처리 → 변환 → 탐색 → 분석 → 시각화 → 해석의 전 과정이 중요합니다. 이 순간 파이썬은 단순히 프로그램을 만드는 언어에서 현실의 데이터를 이용해 질문에 답하는 연구도구로 바뀝니다.

1학기 책과 어떻게 연결되는가

1학기에는 데이터 분석·시각화 예제를 만들어 보았다면, 후속 독서에서는 실제 데이터를 구조적으로 정리·변환·분석하는 방법을 배웁니다. 프로젝트 한 개 → 데이터과학의 작업 흐름으로 성장합니다.

이런 학생에게 특히 추천

게임이나 앱을 만드는 것보다 데이터를 정리하고 패턴을 찾아내는 것이 재미있었던 학생

생각해 볼 질문 — 현실에서 얻은 불완전한 데이터를 컴퓨터가 분석할 수 있는 형태로 바꾸려면 어떤 판단이 필요할까?

추천 판단: ★★★★★

『이펙티브 파이썬 3판』

브렛 슬라킨 · 소프트웨어공학 · 파이썬 코드 품질
🔴 도전
왜 추천하는가

이 책은 1학년용이 아니라 3학년 도전 독서로 배치하는 것이 좋습니다. 프로그래밍을 처음 배울 때 목표는 ‘코드가 실행된다’이지만, 프로젝트가 커지면 기준이 달라집니다. 다른 사람이 읽을 수 있는지, 몇 달 뒤 내가 다시 봐도 이해할 수 있는지, 기능을 바꾸기 쉬운지, 오류 가능성을 줄였는지, 같은 코드를 불필요하게 반복하지 않는지가 중요해집니다. 즉 working code에서 good code로 넘어가는 단계입니다.

무엇을 배울 수 있는가

프로그램이 50줄일 때에는 a, b, x 같은 짧은 변수 이름도 본인이 기억할 수 있습니다. 하지만 5,000줄이 되고 친구와 함께 개발한다면 이야기가 달라집니다. 이때 중요한 것은 컴퓨터가 이해하는 코드가 아니라 사람도 이해할 수 있는 코드입니다. 함수와 클래스, 예외처리, 반복 가능한 객체, 동시성 같은 기능을 ‘쓸 수 있는가’에서 ‘언제 어떤 방식으로 쓰는 것이 적절한가’로 질문을 바꾸게 됩니다. 이것이 소프트웨어공학적 사고의 시작입니다.

1학기 책과 어떻게 연결되는가

1학기에는 프로그램을 완성하는 것이 목표였다면, 3학년에는 유지보수 가능하고 명확하며 안전한 프로그램을 만드는 것이 목표가 됩니다. 코딩 → 소프트웨어 개발로 성장합니다.

이런 학생에게 특히 추천

코드가 돌아가는 것보다 구조를 깔끔하게 만들고 더 좋은 코드로 고치는 것이 재미있는 학생

생각해 볼 질문 — 같은 기능을 수행하더라도 읽기 쉽고 수정하기 쉽고 오류 가능성이 낮은 코드는 무엇이 다를까?

추천 판단: ★★★★★

『밑바닥부터 시작하는 딥러닝 1』

사이토 고키 · 인공지능 · 머신러닝 · 신경망
🔴 도전
왜 추천하는가

원도서 후반부에는 인공지능 관련 프로젝트도 들어 있습니다. 그렇다면 다음 질문은 ‘라이브러리가 결과를 내 주는 것은 알겠는데, 그 안에서는 실제로 무슨 일이 일어날까?’입니다. 이 책은 파이썬을 이용해 딥러닝의 핵심 원리를 직접 구현하게 하므로, AI 프로그램을 사용하는 단계에서 AI 알고리즘을 이해하고 구현하는 단계로 넘어가게 합니다.

무엇을 배울 수 있는가

사진을 입력하면 사람이 있는지 분류하는 프로그램을 만들었다고 해 보겠습니다. 이제는 AI가 사람의 특징을 어떻게 숫자로 표현하는지, 입력 데이터가 신경망을 통과하면 어떤 계산이 일어나는지, ‘정답과 얼마나 틀렸는가’를 어떻게 숫자로 측정하는지, 그 오류를 줄이기 위해 가중치는 어떻게 바뀌는지를 살펴봅니다. 핵심 흐름은 입력 → 신경망 계산 → 출력 → 손실 계산 → 가중치 수정 → 반복 학습입니다. 이 과정에서 함수·행렬·미분·확률이 왜 AI에 필요한지도 코드와 함께 이해하게 됩니다.

1학기 책과 어떻게 연결되는가

1학기 책에서 AI 응용 프로그램을 실행했다면, 『밑바닥부터 시작하는 딥러닝 1』에서는 AI가 학습하는 계산 과정을 직접 구현합니다. AI 활용 → AI 원리로 이동합니다.

이런 학생에게 특히 추천

AI 라이브러리를 사용하는 것보다 신경망이 실제로 어떻게 학습하는지를 코드로 직접 구현해 보고 싶은 학생

생각해 볼 질문 — 머신러닝 라이브러리의 함수를 호출하지 않고도 신경망의 학습 과정을 직접 코드로 구현할 수 있을까?

💡 ‘파이썬을 잘한다’는 말도 여러 뜻이 있습니다

파이썬은 학문 분야 자체가 아니라 여러 문제를 해결하는 도구이자 프로그래밍 언어입니다. 문법을 능숙하게 쓰는 것, 효율적인 알고리즘을 설계하는 것, 실제 데이터를 분석하는 것, 큰 프로그램을 유지보수 가능하게 만드는 것, AI의 학습 원리를 구현하는 것은 서로 다른 능력입니다. 이번 Map은 그 차이를 직접 경험하게 합니다.
